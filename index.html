From slow pages to slow milliseconds

I started on the front end, moving a retail banking app from AngularJS to Vue.js, and learned quickly what a slow page feels like to the person waiting on it.

Then I moved to the back end, where slow is measured in milliseconds and money. I like problems where a lot of data arrives at once and has to be right: Kafka streams, batch loads, retries that heal a network hiccup, and dashboards that raise the alarm before anyone has to ask.

Having built both sides of the screen, I design services that are kind to the people consuming them.

Where I've worked

  1. Oct 2022 – now

    Backend Engineer

    Lloyds Technology Centre, Hyderabad

    Modernizing the Front Office rates trading platform on the Rates Re-Architecture project (RDA & Beacon). I build Spring Boot microservices and Kafka streaming pipelines for the Rates Data Aggregator, along with the REST APIs and ingestion services that pull data from several enterprise trading systems. RDA feeds Beacon analytics, so pricing, risk and P&L calculations run at low latency, and I keep an eye on all of it with Splunk, Grafana, Prometheus and JMX.

  2. May 2021 – Oct 2022

    Software Engineer

    Wissen Technology, Bengaluru · client: Morgan Stanley

    Built the data exchange layer that let Morgan Stanley Investor Services outsource investor servicing to SEI. I designed Spring Boot REST APIs that deliver reference data files to third-party vendors, and replaced shell scripts with a Spring Boot console application that made jobs 60% faster and easier to debug. Retry logic cleared out transient HTTP and network errors, Spring Batch loaded user files into DB2, Autosys scheduled the jobs, and JUnit tests reached 80% code coverage.

    Capgemini, Chennai · client: ABN-AMRO

    Rebuilt retail banking applications for ABN-AMRO on Vue.js while they moved to a public cloud. I migrated a front end from AngularJS to Vue.js one slice at a time, cut load time by 30%, and tested with Jest and TestCafe to 90% code coverage. I also built in accessibility and internationalization, and turned UI/UX wireframes into responsive, cross-browser pages while estimating new features with the scrum master.
